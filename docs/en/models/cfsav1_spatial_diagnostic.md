# 实验：空间动态权重是否发挥作用

## 问题与假设

检查当前局部＋全局 CFSAv1 是否依赖门控图的空间变化。仅改变同一份最佳权重的推理计算，
不重新训练、不修改数据集、不用论文表格或旧训练日志代替本次对照。

## 两组设置

| 组别 | 频带调制系数 |
| --- | --- |
| 原始动态组 | 保留每张图、每个通道组、每个频带的空间调制系数 |
| 空间均值组 | 将上述每张调制图替换为它自己的空间均值，广播到所有位置 |

计算顺序：局部 logits＋全局 logits → tanh → rho 与 gate_scale → 可选门控平滑 → 空间均值。
不对不同图像、通道组或低中高频相互求平均；不把系数全部置 1；原有全局上下文仍然保留。
必须在非线性之后平均：`mean(tanh(z))` 不等于 `tanh(mean(z))`。
旧 `tmp/check_cfsav1_spatial_gate.py` 针对无全局分支的渐进版，不能直接用于当前权重。

## 固定条件

使用最新全局版第117轮最佳权重；同一完整验证集（1532张图），img_size=1600、rect=True、
batch=8、workers=0、FP32、conf=0.001、NMS IoU=0.7、max_det=300，关闭测试时增强。
FP32 用于减少极小门控差异被半精度舍入掩盖；两组必须采用相同精度。
保存权重 SHA256，并在完成后确认文件未改变。脚本带有诊断 hook，耗时不作为推理速度对比。

## 记录与判断

主指标是 Mask mAP50:95、Mask mAP50，补充各类别 AP、P/R、门控空间标准差和平均增益。
P/R 来自验证器选定的工作点，不能当成固定置信度下的检出率差异。

- 均值组明显下降：说明这份权重在推理时依赖空间变化，可继续研究区域选择。
- 两组接近：说明当前权重对空间变化依赖较弱，后续应检查门控的判别依据。
- 均值组提高：空间波动可能包含无益成分，但仍需排查类别差异和泛化，不能直接认定应删除局部门控。

首先报告差值的实际大小，不设任意阈值就宣称统计显著。若差异只有数值舍入量级，
不能据此认定存在实质收益。该实验只诊断现有模型，不能证明从头训练的固定权重方案也会等效。
均值仍由每张图自身的局部特征计算而来，并不是数据集级固定权重。
