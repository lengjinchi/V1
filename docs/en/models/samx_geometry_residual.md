# SAMX 几何残差试验

## 核心改动

原 SAMX 将普通卷积分支与可变采样分支的完整输出按门控权重相加。此次变体保留普通卷积主路径，只额外加入采样位置发生变化所带来的差值：

\[
T=H(X),\qquad Y=C(T)+\gamma\{D(T,\Delta p)-D(T,0)\}.
\]

- `H`：每一阶段共享的特征提取结构。
- `C`：普通卷积、BN 与激活，承担基础特征提取。
- `D(T, Δp)`：按学习到的偏移位置采样，再进行线性聚合。
- `D(T, 0)`：按固定位置采样，使用与偏移分支完全相同的聚合权重。
- `gamma`：每阶段一个可学习标量，初始值为 `0.1`。

两个 D 分支内部均不使用 BN 或激活，以保持差值的含义。代码先对采样特征求差，再使用一次共享线性聚合，避免重复聚合和大数相减。

偏移卷积的权重、偏置均从 0 开始，因此初始修正量严格为 0，每阶段先等同于自己的普通卷积路径。`gamma` 从非零值开始，使偏移分支能收到梯度。它并不等同于完整原 SAMX 的初始输出。

## 为什么试这一版

前一轮 LocalGlobal 模型在同一权重上的验证中，将空间门控改为空间均值后，Mask AP50:95 从 26.4078% 变为 26.3899%；将偏移置零后则变为 23.8360%。这提示该权重中偏移采样有作用，而现有局部门控的贡献较小，值得尝试直接学习几何修正。

上述结果是推理干预证据，不能替代重新训练的对照。本次还将每阶段的双特征提取路径改为了共享路径，因此它是完整结构变体，不能把结果全部归因于取消门控。

## 本次训练

入口：`seg_train.py`。独立记录入口：`run_samx_geometry.py --train`。

```python
samx_mode="geometry_residual"
samx_geometry_gain=0.1
samx_offset_lr_scale=0.1
use_cfsa=False
use_cfsav1=False
```

仅替换 nano 模型原来的 `vajra_neck3`，接入位置保持 P4；原版、StageGlobal、LocalGlobal 均继续保留。MABD、配对训练、参考监督和 CFSAv1 的冻结/渐进调制均不参与本次训练。

使用与上一轮相同的钢材表面缺陷数据划分：训练 6134 张，验证 1532 张、3942 个实例。从头训练，不加载已有权重。配置为 200 轮上限、早停 30、图像尺寸 1600、rect=True、batch=32、AMP、seed=42、workers=0；SGD lr0=0.01、momentum=0.9。偏移参数学习率为普通参数的 0.1 倍，并在学习率预热期间保持该比例。

训练结束后，脚本自动加载最佳权重，以 FP32、batch=8 在完整验证集复核，并生成与前两项试验的指标对比。论文中的 SAMX 单模块行仅作为历史参考，本次不补跑用户已取消的修复原版对照。
