# MABDv1 完整版独立实验

只训练完整改进版，不重训原 MABD，不排入两项单独消融，不修改正样本平均方式。

## 损失设置

- `mask_loss_mode=bce`：原普通掩膜 BCE，默认设置。
- `mask_loss_mode=mabd`：保留的原 MABD（框长宽比 + 填充率，原 GT 框）。
- `mask_loss_mode=mabd_v1`：内边界占比 q=(G-erode3(G)).sum/G.sum；Dice 权重 0.30+0.20q，边界权重 0.05+0.15q。
- 完整版主体 BCE、Dice 保持原 GT 框；边界带及监督框扩张 1 个原型像素（3×3 膨胀减腐蚀）。框坐标裁剪至有效画布范围，边界项按实际有效边界像素数归一化。
- q 从完整实例掩膜计算，使用显式零填充的腐蚀；它是内边界占比，具有尺度和离散方向依赖，不称为严格旋转不变或拓扑指标。
- 损失统计采用 FP32。若下采样后的 GT 为空，q=0、边界项为零；保留原主项，记录空掩膜诊断供后续检查。
- 正样本平均保持原逻辑。SAMX、原 CFSA、CFSAv1、Proto 几何分支全部关闭。

`runs3/steel segment Vajra-new improvebceloss/Vajra-new loss/weights/best-vajra-v1-nano-seg.pt`。

该权重的原 criterion 保存 Dice 基础权重 0.3、形态增量 0.2、边界系数 0.15；网络为普通 VajraV1MerudandaX，未启用 CFSA。旧版本没有损失模式开关。保留其权重和 CSV，仅完整验证，不重新训练、不用于初始化新模型。

训练沿用该实验：最多 300 轮、早停 30，1600、rect=True、batch32、AMP、seed42、workers0。旧 auto 优化器在此训练规模下实际选择 SGD(lr=.01,momentum=.9)，将 warmup_bias_lr 置零；本次显式设置相同有效值。历史源码和随机状态无法完整复原，因此仍需注明历史对照的可比性限制。
